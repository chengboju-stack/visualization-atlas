# 可视化导论 · 重构版（Visualization Atlas）

对 <https://cinger007.github.io/vis/> 的重构实现。**内容零改写**：老师的 27 个小节、代码、
理论引用与 27 个可运行演示全部保留；重构的是「怎么呈现、怎么找、怎么知道自己在哪」。

本地预览：

```sh
cd site
python -m http.server 8770
# 打开 http://127.0.0.1:8770/
```

---

## 一、为什么这样改

原站的问题是「每一节长得一样」：27 个小节共用同一套「讲解 / 代码 / 演示」三 tab，
`你的原案例` 与 `嵌入理论` 平级混在同一个面板里，五章之间是什么关系没有任何表达，
很多天然该是图形的概念只有文字。学习者读完不知道自己在哪、哪些是必学、哪些是扩展。

本次重构针对这四点：

| 原来 | 现在 |
| --- | --- |
| 27 节同一模板，长页面里没有方位感 | 左侧常驻目录（编号 + 三层标记）、阅读进度条、上部章节脊、底部上下节翻页 |
| 案例与理论平级混放 | 内容按层切块：案例（朱砂竖线）/ 理论（青灰底）/ 扩展（虚线可折叠）/ 代码（独立卡）/ 演示（仪器壳） |
| 五章关系没有表达 | 门户新增**知识地图**：箭头表示前置关系，悬停只看相关链路 |
| 概念只有文字 | 门户新增**图表选型器**（9 类数据关系）；新增**九个概念实验台**（见第四节） |
| 43 个演示各自为政 | 统一演示容器：实时运行指示灯 + demo id；统一的表格/按钮/日志/色卡样式 |
| emoji 当图标 | 全部换成内联 SVG；代码里的 ⭐ 换成 ◆ |

## 三、对原站代码的改动（只有这些）

1. **D3 本地化**：原来 `lesson.js` 从 `cdn.jsdelivr.net` 以 ESM 导入 D3，
   断网或 CDN 被墙时所有演示都会失效。现在改为加载 `vendor/d3.min.js`（UMD），
   `import * as d3 from "…"` 换成 `const d3 = window.d3`。
2. **点小节不再强制跳到「演示」tab**：原站 `__activateChapter` 会在切换小节时
   自动把标签页切到「演示」并滚动过去，把你正在读的讲解盖掉。已移除该行为，
   保留当前 tab 与滚动位置。
3. **去掉标题与标签页上的 emoji**（📖 ⌨️ ▶️ ⭐ 📌），改为统一文字标签与 SVG 图标。
4. **代码里的 ⭐ 标记换成 ◆**，避免 emoji 在不同系统上渲染不一致。

除此之外，`lesson.js` 的演示逻辑、`i18n.js`、`data/` 下的数据文件均未改动。

## 四、九个实验台

每个实验台只讲一件事，全部为原生 JS + SVG/Canvas，无第三方库。

| # | 实验台 | 讲什么 | 怎么交互 |
| --- | --- | --- | --- |
| 01 | **Data-Join 三态** | enter / update / exit 的真实差分 | 改数组、切 key 函数；滚动叙事四步 |
| 02 | **DIKW 四层** | 同一数据在四个层级上含义不同，每层有损耗 | 滚动叙事，金字塔逐层点亮 |
| 03 | **视觉通道排序** | Mackinlay 1986 的感知精度排序 | 切「定量 / 有序 / 定性」，通道实时重排、失效项变灰 |
| 04 | **Marching Squares** | 16 种角点情形 → 查表连线 | 拖阈值、单步推进 96 个格子，当前格标出四角值与 case |
| 05 | **色阶三族** | 顺序 / 发散 / 定性对应三种数据语义 | 语义 × 色阶任意组合，错配时给出具体"哪里说错了" |
| 06 | **色盲模拟** | Machado 2009 生理模型 | 三种缺陷实时切换，同时看色板、柱状、折线 |
| 07 | **CIELAB 色域** | 屏幕能显示多少颜色 | 拖 L* 扫过 a\*b\* 平面；点图取色读出 Lab |
| 08 | **日历热图** | van Wijk 布局 + brushing & linking | 日历框选，下方趋势线同步高亮并给出区间均值 |
| 09 | **阿基米德螺旋** | 周期在极坐标里显形 | 拖折叠滑块 / 播放，时间轴卷成螺旋 |

## 五、构建

章节页由 `build/build-lessons.cjs` 从 `src/`（老师仓库的原样副本）生成：

```sh
node build/build-lessons.cjs
```

脚本做三件事：抽出每节的 `<article class="chapter">` 原样保留、重建外层骨架、
打补丁到 `lesson.js`。所以**不要直接手改 `site/lesson-0N/index.html`**，改脚本再重新生成。
