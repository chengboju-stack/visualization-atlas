从数字到判断：DIKW 四层 From numbers to judgement: DIKW

同一个数据，在四个层级上说的是完全不同的话。往下滚，看一份新生数据怎么一层层长出含义——以及每一层丢掉了什么。 The same data says different things at each level. Scroll to watch a freshman dataset gain meaning layer by layer — and notice what each layer throws away.

  1. 01Data 数据Data

    原始记录：一行一个学生，一列一个字段，没有任何解释。Raw records: one row per student, one column per field, no interpretation.

  2. 02Information 信息Information

    加上单位、口径和聚合，数字才成为可读的陈述：「平均年龄 17.8 岁」。Add units, definitions and aggregation and numbers become statements: "mean age 17.8".

  3. 03Knowledge 知识Knowledge

    把多条信息连起来形成可复用的规律：「年龄集中在 17–18 岁，因为这是大一」。这是关于世界的主张，可以被反驳。Connect statements into a reusable pattern: "ages cluster at 17–18 because these are first-year students". This is a claim about the world, and it can be challenged.

  4. 04Wisdom 智慧Wisdom

    知道该不该用这条规律、用在什么边界内：「这份数据是合成数据，不能用来推断真实人口结构」。图表只能承载前两层，后两层要靠人和标注。Knowing whether to act on the pattern, and within what limits: "this dataset is synthetic, so it cannot support claims about the real population." Charts carry the first two layers; the last two need people and annotation.
