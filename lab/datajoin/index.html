数据变了，DOM 怎么跟着变？ When data changes, what happens to the DOM?

D3 的通用更新模式把新旧数据一比，分成三种情况：enter（新来的元素要创建）、update（已有的元素要改）、exit（多余的旧元素要移除）。往下滚，看这三态怎么在同一个图表里发生。 D3's general update pattern diffs old and new data into three states: enter (create), update (restyle), exit (remove). Scroll to watch all three happen in one chart.

  1. 01初始数据Initial data

    数组 [3, 5, 2]，页面上有三个矩形。Array [3, 5, 2] — three rectangles exist.

  2. 02数据变长了 → enterLonger array → enter

    变成 [3, 5, 2, 7, 4]。前三个是 update，后两个从来没有对应元素——它们从基线"长"出来，这就是 enter。Now [3, 5, 2, 7, 4]. The first three are updates; the last two have no element yet — they grow from the baseline. That is enter.

  3. 03数据变短了 → exitShorter array → exit

    变成 [4, 6, 3]。剩下的两个元素没有数据认领，它们缩回基线后消失，这就是 exit。注意：不调用 exit().remove() 它们会永远留在页面上。Now [4, 6, 3]. Two elements are unclaimed: they shrink to the baseline and disappear — that is exit. Note: without exit().remove() they stay on the page forever.

  4. 04key 函数改变了一切The key function changes everything

    默认按索引配对，所以 [3,5,2]→[4,6,3] 是"每个都改值"。如果改成按值配对，同一个元素会被认成"原来的 3 变成了 4"，另一个则走 exit——这就是对象恒定（object constancy）。By default D3 pairs by index, so the change is "every bar updates". Pair by value instead and the element that was 3 is recognised as now 4, while another exits — that is object constancy.
